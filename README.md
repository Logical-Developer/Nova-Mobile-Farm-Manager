# Nova-Mobile-Farm-Manager

Nova Mobile Farm Manager

## GitHub upload checklist

1. Replace the placeholder GitHub URL in the metadata block of the userscript file.
2. Upload the file to a GitHub repository.
3. Use the raw URL for the Tampermonkey update URL.
4. Keep the file name consistent with the downloadURL.

Example:

```text
https://raw.githubusercontent.com/YOUR_USERNAME/Nova-Mobile-Farm-Manager/main/Nova-FarmManager-Mobile.user.js
```

## Current mobile scope

- Mobile-only scope.
- Multiple lists per village.
- Separate resume state for each list.
- List rename and delete supported in the rally panel.
- Remove-from-list support on the map popup.
- Bulk add/remove import from copied text is supported by the script core.
